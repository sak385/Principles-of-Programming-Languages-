# Principles of Programming Languages 
This repository contains my programming assignments for Principles of Programming Languages. Each assignment is organized into its own folder, containing the relevant source code.

# Assignments
Assignment 1  — OCaml programming assignment focused on calendar dates, list processing, recursion, and functional programming. Implements functions for date comparisons, month calculations, date formatting, cumulative sums, and finding the oldest date, with separate test cases for validation.

Assignment 2 — OCaml programming assignment focused on JSON processing, recursive list operations, and functional programming. Implements JSON serialization, field access through nested objects, duplicate detection, access-path filtering, geographic coordinate validation, and bus route histograms using Rutgers bus position data.

Assignment 3 — OCaml programming assignment focused on functional programming, higher-order functions, recursion, and pattern matching. Implements string processing, list aggregation, wildcard and variable analysis, duplicate variable detection, pattern matching, and matching value extraction using custom data types.

# Languages and Tools
OCaml, PowerShell, VS Code, Dune

# Repository Structure
Each assignment has its own folder to keep the source code organized and separate.
