# Assignment 5: Streams, Caching, and Macros

## overview
This assignment explores functional programming concepts in Racket, including recursive list operations, lazy streams, cyclic data structures, vector-based caching, and macros. The implementation includes functions for generating sequences, manipulating lists and streams, searching vectors, creating a caching association lookup, and defining a custom while-greater macro. This project helped strengthen my understanding of recursion, higher-order functions, delayed computation, and Racket's macro system.
